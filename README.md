# 42 Cybersecurity

Offensive security projects from École 42 — binary exploitation, reverse engineering, and system security fundamentals.

## Projects

### Snow Crash
Introduction to computer security at 42. Explores security across several sub-domains from a developer's point of view: analyzing unfamiliar programs, spotting common programming mistakes, and understanding how they can be exploited (C, x86 ASM, PHP, Perl).

### Rainfall
A binary exploitation wargame: a series of increasingly difficult levels running on a VM. Each level requires reverse-engineering a compiled binary and exploiting a vulnerability (buffer overflow, format string, etc.) to escalate privileges and unlock the next one.

### Override
The follow-up to Rainfall, with harder binary exploitation challenges.
